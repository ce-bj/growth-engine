# AI 营销落地页交互调整

版本：v0.3 · 前端 Mock

本文件定义创建、编辑、发布和效果页的交互规则；与 v0.2 不一致之处以本文件为准。12 个模板和公共组件体系保留。

## 1. 页面数据配置

### 知识目录

用户选择的是知识目录范围，支持多选：企业与品牌、产品资料、行业解决方案、客户案例、活动与展会、服务与常见问题。未选择目录时，生成 Agent 在全部目录中检索。目录范围不等于已确定具体资料；生成时才检索相关内容，缺失的依据再通过上传或对话补齐。当前检索与判断使用 Mock。

知识目录入口在创建和编辑对话中保持一致。目录弹窗提供“使用全部目录”“保存范围”和“上传补充资料”。

### 模板位置与顶部操作

“页面构建方式”明确区分选择模板与自定义组件，下方独立标注“模板库”，消除“选择起点”与模板区域的歧义。创建参数集中在对话框及高级设置内，页面顶栏不再重复显示高级设置。创建入口放在历史列表；编辑过程中通过历史列表管理其他页面，发布完成后可新建。

## 2. 编辑与预览

### 持续可用的对话框

左侧保留“对话”“组件”两个入口，移除重复的“布局与内容”步骤。对话输入区设置明确的最小高度，包含知识目录、表单、产品、设置和上传资料入口。用户无需回首页调整这些数据。

### 元素选区与局部修改

点击画布标题或正文后，文字显示选中边框，选区同步到对话框。用户输入修改需求时，修改作用于选中文字对应的字段。右侧显示文字属性：文字内容、水平对齐、字号、粗细、颜色、透明度。属性修改即时写入当前草稿。

点击首屏图片后，对话框标记图片选区；提出替换图片需求时打开图片选择／上传入口。整块组件仍可拖拽排序，组件库保留添加、显隐、上移和删除。组件顺序与首屏布局作为组件区的辅助设置，不构成新的流程步骤。

当前文字选区覆盖首屏标题、首屏正文和组件标题／正文。组件内部由数据生成的细分条目仍使用所在组件的数据配置，不等同于任意 DOM 节点的自由编辑。

### 表单与版本

移除“测试转化入口”按钮。表单直接出现在落地页内，按照所选字段集合呈现输入和演示提交反馈。页面 CTA 优先滚动至已有表单；未设置表单组件时使用演示弹窗。表单字段配置在对话工具栏中。

编辑过程保存草稿，不记录过程版本。每次确认发布形成一个发布版本，包含时间、标题和页面快照；发布版本窗口可打开指定版本预览。未发布时无版本记录。

## 3. 发布配置

移除“推送目标意图”选择项。每个推广位置共用三组配置：

| 配置组 | 内容 |
|---|---|
| 访客行为 | 停留时长、滚动深度、浏览页面数量、浏览总时长、满足条件数量 |
| 展示范围 | 网站导航页多选：首页、产品中心、解决方案、新闻资讯、公司介绍、联系我们 |
| 时间频次 | 每日开始／结束时间（UTC+8）、同一访客展示间隔、24 小时最大展示次数 |
| 展示形式 | 入口文案、适用设备 |

首屏 Banner 的展示范围固定为首页，相关范围和行为阈值置灰；触发关系固定为进入首页。侧边广告位仅支持电脑。其他位置使用相同配置结构，并允许多选导航范围。已启用的推广位置未选择范围时提示补充。

五个推广位置分别配置，保留首屏 Banner、页中横幅、侧边广告位、底部弹出、智能客服推送。页面预览模拟门户内的小型推广入口，点击跳转完整落地页。支持电脑、平板、手机切换；侧边广告位在非电脑设备下不显示推广卡片。底部与客服卡片可关闭并重新预览。

本次保存配置及呈现预览，不实现真实访客行为采集、时间调度、频控服务或线上投放。

## 4. 效果页

访问来源分为站内推广入口跳转、直接访问链接、搜索／广告／社媒外链，并继续按推广位置展示曝光、点击、到达和转化。

转化线索区域仅提供“进入线索管理”按钮，不在效果页重复展示联系人表格。原型跳转至平台线索管理接入占位页，后续替换为平台真实地址。

## 5. 修改文件与交付状态

- `MarketingStudio.tsx`：目录范围、对话编辑、发布版本、流程入口、效果来源与线索跳转。
- `StudioStart.tsx`：构建方式与模板区域关系。
- `StudioCanvas.tsx`：文字／图片选区、文字样式、页面内表单与 CTA。
- `TextInspector.tsx`：右侧文字属性面板。
- `StrategyEditor.tsx`：统一推广策略与多设备预览。
- `PlacementPreview.tsx`：小型入口及设备适用提示。
- `studio.css`：对话输入区、右侧属性面板及推广预览样式。

本次修改已保存，不进行浏览器验收或运行测试，由使用者验证。真实 Agent、知识检索、发布服务、线索管理和统计接口仍为后续接入范围。
