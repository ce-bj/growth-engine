## 启动

在 `marketing-frontend` 目录执行：

```sh
npm run dev -- --host 127.0.0.1 --port 5186 --strictPort
```

访问 http://127.0.0.1:5186/ 。`npm run build` 构建。

当前入口为 `src/App.tsx` → `MarketingStudio`。当前为前端 Mock，生成请求及本地草稿已构建，真实模型、知识检索、响应校验与正式发布尚未接入。完整拼合示例见统一文档第 11 章；版本与验收见第 12 章；模板预设、连续生成与组件契约见第 13–15 章。
