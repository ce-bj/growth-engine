# 营销落地页工作台 v0.2

前端可点击 Mock。入口为 `src/App.tsx`。

完整设计说明：[`document/AI营销落地页-模板组件与交互升级-v0.2.md`](../../../../document/AI营销落地页-模板组件与交互升级-v0.2.md)。

## 运行

在 frontend 目录执行：

```sh
npm run dev -- --host 127.0.0.1 --port 5186 --strictPort
```

访问 http://127.0.0.1:5186/ 。构建使用 `npm run build`。

## 操作

历史页面列表 → 创建页面 → 输入需求 → 选择 12 个模板之一或自定义组件 → 确认目标市场、语言、主色调、字体风格 → 直接生成。

缺少知识、图片或产品时显示占位，在对话区逐项补充。编辑区提供对话、组件库、布局与内容，支持电脑、平板、手机预览。发布可选择仅链接或配置五种推广位置，效果页提供示例分析和优化入口。

数据保存在当前浏览器；多个页面分别保留，已发布页面保存独立快照。模型生成、RAG、知识解析、意图识别、SSR、发布与统计均未接入后端。现有后端和原版页面文件保留。

最新交互调整以 [v0.3 文档](../../../../document/AI营销落地页-交互调整-v0.3.md) 为准：知识目录可选、多目录检索范围、对话与右侧文字属性联动、仅发布版本、统一推广配置和线索管理入口。本次未运行验收。
