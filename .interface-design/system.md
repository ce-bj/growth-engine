# 增长工作台 · Precision & Density

操作台，不是看板墙。人打开页面是来拍板的：先看到该处理的一条，数字只提供上下文。

## Direction

- Feel: 工程图上的修订墨线。冷灰纸面仍是结构，AI 写过的诊断用一层蓝图墨迹标出来。
- Depth: borders-only。禁止投影和铺满整页的渐变。墨迹只用半透明底，不用发光。
- Density: 工作台紧。同一套数字重复使用。
- Accent: `#3989FF` 是修订墨，表示「AI 准备好了，现在就做」。琥珀色只表示「还要人决定」。跌幅用淡红轨标出，数字本身保持墨色。

## Tokens

定义在页面根上，组件读变量，不写散落的 hex。

| Token | Value | Use |
| --- | --- | --- |
| `--desk` | `#f5f7fb` | 画布、指标格、筛选底 |
| `--sheet` | `#ffffff` | 纸面 |
| `--ink` | `#0f172a` | 主文字、主数字 |
| `--ink-soft` | `#475569` | 次级标题、说明 |
| `--ink-faint` | `#94a3b8` | 已完成轨、圆点，不用于正文 |
| `--ink-meta` | `#64748b` | 更新时间、对照值、计数 |
| `--rule` | `rgba(15, 23, 42, 0.08)` | 分隔、指标格 |
| `--rule-strong` | `rgba(15, 23, 42, 0.14)` | 焦点纸面外框 |
| `--stamp` | `#3989ff` | 修订墨线、主按钮、待发布轨 |
| `--stamp-ink` | `#1d4ed8` | 蓝字：标记、状态词、链接。白底达到 4.5:1 |
| `--trace` | `rgba(57, 137, 255, 0.08)` | AI 写过的纸面 |
| `--trace-line` | `rgba(57, 137, 255, 0.28)` | AI 纸面的边 |
| `--decision` | `#b45309` | 待决定文字 |
| `--decision-rail` | `#d97706` | 待决定 2px 轨 |

## Spacing

基数 4。只用 4 / 8 / 12 / 16 / 24。

| 位置 | 值 |
| --- | --- |
| 页面区块间距 | 12 |
| 焦点区块额外上边距 | 12（与上一块合计 24） |
| 纸面内边距 | 12 × 16 |
| 行内边距 | 12 × 16 |
| 指标格间距 | 8 |
| 指标格内边距 | 12 |
| 筛选项间距 | 4 到 8 |

## Radius

- 纸面 6
- 按钮、筛选、指标格 4
- 不使用 10、12 或全圆胶囊作为结构容器

## Type

比例约 1.2。字重和颜色承担层级，不只靠字号。

| 角色 | 规格 |
| --- | --- |
| 页标题 | 16 / 600 / `--ink`，字距 -0.01em |
| 区块标题 | 16 / 600 |
| 决策标题 | 18 / 600 |
| 正文、行标题 | 14 / 500，下一条待办 600 |
| 说明 | 13 / 400 / `--ink-soft`，行高 1.5 |
| 涨跌、时间 | 12 / 500，时间用等宽 |
| 指标名、状态词 | 11 / 500–600，字距 0.02–0.04em |
| 指标数字 | 22 / 600，等宽，`tabular-nums`，字距 -0.02em |

## Buttons

高 32，左右 12，字号 13 / 500，圆角 4。当前主题若把默认按钮做成 40，这一页用 32。按钮颜色跟操作走，不跟行号走：同一种操作同一种按钮。「去预览发布」用 `primary`，「去批策略」「去优化」用 `default`。

## Sheet

纸面：1px `--rule-strong`，圆角 6，背景 `--sheet`，无投影。上下文纸面（指标、说明）用更轻的 `--rule`。

## Metric cell

指标名在上，数字居中，涨跌在下，对照值贴底。

- 名：11 / 500 / `--ink-soft`
- 数：22 / 600 / `--ink`，不因涨跌改色
- 跌：`#dc2626` + 向下箭头。格上只加 2px 红轨，不铺红底
- 涨：`#16a34a` + 向上箭头
- 平：`--ink-soft`，写「与上周持平」
- 格：边框 `--rule`，背景 `--desk`，圆角 4，间距 8
- 悬停只改边框到 `--rule-strong`，不位移、不加投影

## Queue row

待办、优化策略箱用同一种行，不做成一张张小卡。

- 行高内容区 padding 12 × 16
- 行间 1px `--rule`，最后一行不画
- 左侧 2px 内嵌轨：待决定 `--decision-rail`，待发布 `--stamp`，已完成或先不做 `--ink-faint`
- 状态词无底色：11 / 600。待决定 `--decision`，待发布 `--stamp-ink`，其余 `--ink-soft`
- 标题 14 / 500，当前选中或下一条 600
- 时间、影响 12，等宽数字
- 悬停背景 `rgba(15, 23, 42, 0.04)`
- 选中背景 `rgba(57, 137, 255, 0.06)`，轨保留状态色
- 行本身是按钮时，焦点环 2px `--stamp`

## Filter

一组里只能有一个选中项，带等宽计数。

- 宽队列：Ant Design `Segmented` `size="small"`，高 32
- 窄清单：同样的高度、圆角 4、边框 `--rule`、选中字色 `--stamp-ink`
- 不要按类别涂橙、蓝、紫、绿

## Decision bar

决策条是 AI 写给操作者的一句说明。背景 `--trace`，边框 `--trace-line`，圆角 4，左侧保留状态轨。主按钮留在条的右侧。

## Revision ink

AI 相关的痕迹只出现在它真正写过的地方，不铺满导航和表格。

- 标记：7px 的两粒蓝点加「AI …」13px / 600 / `--stamp-ink`，字距 0.04em。用在页眉、待办标题、诊断头。蓝点仍用 `--stamp`。
- AI 纸面（诊断小结、下一条待办、当前选中的策略、诊断格、决策条）背景 `--trace`，必要时加 2px 顶墨线 `--stamp`。
- AI 标出的下跌指标：只留 2px 红轨。数字仍是 `--ink`。
- 漏斗梯形保持图表自己的颜色，不改成墨线纸。
- 智能营销页只改嵌入壳（页眉、页面库、创建参数和生成条）。生成出来的落地页画布保持原样。
- 官网内容发布的首页用同一套纸面：指标格是按钮，内容进展和冷启动是带顶墨线的 AI 纸，策略行用蓝轨，待决定行用琥珀轨。发布任务表本身不铺墨。
