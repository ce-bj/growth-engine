# 内容发布智能体 产品逻辑

## 介入时机

网站即将上线时，智能体介入内容发布全流程。核心是一条主线：先巡检存量内容 → 确认选题方向 → 持续产出与发布 → 进入上线运营。

## 整站巡检

判定对象：站点里已有的内容文章（存量），逐篇巡检，一次性动作。

巡检三步走：

**第一步，逐篇判定**：每篇内容按两项标准判断——EEAT 评分是否低于 80 分、GEO 结构是否清晰、品牌词是否统一。

**第二步，自动修正**：不合规的篇目由智能体自动改写修复，修复后 EEAT 评分补强到 90 以上。

**第三步，只列被修正的**：巡检完成后只把「被修正过的内容」列出来供确认，原本合规的篇目不展示、不动。

特殊情形：某篇修正需要知识库对应内容而知识库暂无时，该篇标为「待补知识库」，在结果页内提示，不阻断巡检，也不弹窗。

依赖知识库的规则：

| 规则 | 依赖内容 | 用途 |
| ---- | ---- | ---- |
| 品牌词表述统一（英文站） | 英文站品牌词库 | 改写英文站内容时，对照词库统一品牌词表述 |

知识库产品为外部只读调用，已接入。仅当某篇修正命中上述规则、且词库中尚无对应内容时，才会进入「待补知识库」状态；其余修正不依赖知识库，可直接自动完成。

## 巡检结果处置

巡检完成后，结果按三种状态分区展示：

| 状态 | 含义 | 可选操作 |
| ---- | ---- | ---- |
| 已修正 | 智能体已自动改写，待确认 | 确认发布 / 暂不发布 |
| 待补知识库 | 缺少「英文站品牌词库」内容，暂未修正 | 上传后继续修正 / 暂不处理 |
| 已发布 | 已确认发布，进入上线运营 | 仅显示「已发布」，无操作 |

出口规则：

- 底部只保留一个出口按钮「进入运营看板」。
- 只要还有「待确认」或「待补知识库」的篇目，按钮禁用，并显示剩余待处理数量。
- 不自动跳转，保留全部修改明细供用户逐篇处理。

## 运营看板

判定对象：巡检通过后的运营状态与推荐。

准入条件：完成整站巡检后进入。巡检是一次性动作，做过一次后看板长期可用，不再重复拦截。

看板四个模块：

| 模块 | 展示内容 |
| ---- | ---- |
| 总计数据 | 累计发布数、本周发布数、本月发布数、累计修正篇数 |
| 上线初始推荐 | 一个博客类发布任务（给方向，不是成稿） |
| 发布状态 | 今日已发布 / 今日待发布，卡片式，点卡片看正文与策略 |
| 生产内容策略 | 智能体生产内容时采用的策略 |

## 长期运营：访客行为指令

网站上线并进入长期运营后，内容发布智能体定期从访客行为智能体接受指令，据此生产或修改内容。

判定对象：访客行为智能体定期输出的内容指令。

指令三类：

| 指令类型 | 输出的内容 | 智能体的动作 |
| ---- | ---- | ---- |
| 生产主题 | 该生产的主题 | 据此新建内容 |
| 修改方向 | 该修改的方向 | 据此修订对应内容 |
| 定位信息 | 对应内容的链接、标题 | 据此定位到具体内容再修改 |

触发方式：环境感知、监控驱动、排程生成、主动补强旧文等，由访客行为智能体按周期发出。

## 上线初始推荐

判定对象：网站刚上线时，智能体推一个「博客类」发布任务。

合格标准：只给选题方向，不给成稿；附带目标日期与生产策略。

处置：确认后生成一个发布任务并开始排产；可调整标题与目标日期；生产策略由智能体设定，只读不可改。

## 生产内容策略

智能体生产内容时统一采用四类策略：

| 策略 | 口号 | 说明 |
| ---- | ---- | ---- |
| EEAT 强化 | 让每篇内容有据可依 | 补强经验 / 专业 / 权威 / 可信，附作者资质与数据出处 |
| GEO 4 项 | 让 AI 引擎优先引用你 | 结构清晰、问答对齐、实体明确、引用规范 |
| 红线自检 | 上线前零违规风险 | 发布前自动检测规避违规、敏感表述 |
| 权威信源 | 每个结论都可核验 | 关键结论附可核验来源 |

## 发布任务

判定对象：一套持续产出内容的生产规则。

规则：任务本身不可发布，可发布的永远是它产出的一条内容；一个任务按节奏持续产出多条内容。

任务来源两类：

| 来源 | 说明 |
| ---- | ---- |
| 智能体排产 | 由确认的选题方向自动生成 |
| 手动创建 | 用户自定义主题、关键词、频率、产出量 |

## 内容中心

判定对象：所有内容与任务的管理视图。

统一内容库：把「巡检存量文章」与「排期内容」归一成同一结构，同标题自动合并。

内容状态四类：已发布 / 已修改（待确认）/ 计划中 / 待发布。

视图：

- 内容页签：列表视图（全部 / 待发布 / 已修改 / 已发布）+ 日历视图。
- 任务页签：进行中 / 已暂停的任务列表。

## 再次检查

出现条件：巡检的待处理项（待确认 + 待补知识库）全部清零后，才解锁进入运营看板。
