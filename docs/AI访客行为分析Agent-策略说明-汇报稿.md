# AI 访客行为分析 · 策略说明

范勇健 · 2026-09-11

按这个顺序讲：客户站上要解决什么 → 产品长什么样 → Agent 怎么判 → 人在站上每一步会卡在哪 → 活交给谁。

---

## 1. 需求背景

客户把人招到官网，要的是询盘。人到了以后看几秒就走，运营只能凭感觉改一版详情，再等两周看询盘有没有回来。平台这边，运营助手已经能发页、改页。缺的是告诉他改哪一页、为什么改。

9 月规划把这件事放在诊断层。先看清这段日子人卡在哪，再把活交给内容运营去做页、交给客服去接询盘。全站留资转化是总目标。诊断把「卡在哪一层、钉哪一页」说清楚，后面的智能体才有地方下手。

规划里诊断还要认访客从哪类词来、处在采购的哪一段。这件事要等搜索词、广告词能对上到访的人，再接。一期先把流失定位跑通：客户问询盘少了，我们能指到层、指到页，并带上该干什么。

---

## 2. 产品形态

客户在数字门户打开「访客行为分析」，看到的就是这次诊断。

上头几句话：这段日子来了多少人、询盘几条、卡在哪一层、钉在哪一页、下一步谁来干。下面是漏斗：来了、看进去、动手、留下，四段都是人数。点卡住的那一层，右边把页面拆开。还想核对，再看几个访客当天从哪进、停多久、走到哪。

漏斗指出卡在哪一层、哪一页。路径把几个真实访客当天的走法摊开。两步对上同一份结论，运营按这份结论去改。

从运营助手里问「询盘少了」，先听到这几句结论，再点进同一页。窗口重算完可以推一条通知，点开还是这页。做内容的人从建议上能回到这页看依据。

漏斗按人数走。询盘条数写在旁边，方便对业务；层高用留下了多少人。

---

## 3. Agent 策略

Agent 看近 28 天，对比再往前四周的平均。数可以每天重算，判断始终针对这一段日子。自然月要出月报，另做一份。

先看三个通过率：来了之后有多少人看进去，看进去之后有多少人动手（开填表单或主动开聊），动手之后有多少人留下。相对上期掉得够多——比例掉过 10%，绝对值掉过 2 个百分点——这一层记为异常，全站结论就写卡在这里。

这一层异常了，再看渠道、再看页面。一页自己的通过率也掉了，就钉这一页。好几页一起掉，就请运营把这几页放在一起看。停留和滚动用来印证，人是不是停在第一屏。

钉住以后，抽几个人看当天完整路径：从哪一页进站、停了几秒、有没有第二页、最后走到哪。用来确认漏斗上的判断。

指标对得上假设库里哪一条，就把那条原因和对应的活交出去。按这段日子大概能多留住多少人来排顺序。

渠道按进站第一页算。搜索、直接访问、外链、广告四条加起来，等于全站人数。

---

## 4. 网站里可能的根因

按人在站上走的顺序找。哪一步的通过率掉了，就在哪一步里对原因。假设库里有 17 条，下面按这条路摊开。

人从外面进来。某一条渠道人少了，投放、搜索或外链出了状况。来的人总数差不多，差渠道变多了，结构会变差。原来能带来人的词，展现或点击掉了，入口会越来越窄。进来的如果多是「怎么选」「指南」，厂家、OEM、起订量又没有页接，后面的转化会虚。

人到了第一页。第一屏还在讲公司，型号和参数在下面，采购看几秒就会走，看进去的比例就会掉。广告词是询价，页上却在讲品牌，这一渠的人也会在第一页走掉。搜索词和页上写的不是一回事，这个词会掉，同一页上别的词可能还正常。人数涨、秒退也涨，要先看是不是无效访问。

我们用来演示的站就停在这一步：人没少，看进去的比例从 40% 掉到 30%，钉在主力型号详情。首页、文章、营销页在这一层还稳。

人看进去了，接着要询价。很多人停在文章、列表、关于我们，根本没到详情，详情入口要补上。到了详情找不到报价入口，或者按钮写着「联系我们」「Submit」，采购不知道点了会怎样。规格、认证、怎么报价、工厂实拍、出口案例缺一块，看完也写不出询盘。站内搜型号搜不到，人会直接离开。

人已经开始填表或开聊。客服越聊越空，留下的会少。表单一上来就要国家、采购量，填到一半会走。表单和客服哪边掉，就看哪边。

停留短、滚动浅，用来印证上面这些判断。

---

## 5. 解决方案

原因指到页上的字和模块，就改现有页。第一屏改成型号和给谁用，参数挪到第一屏。按搜索词、广告词重写第一屏。看得见的地方补「获取报价」「要样品」。把规格、认证、报价方式、案例补齐。文章和列表链到详情。这些走运营助手的修改产品、修改内容。

原因指到站里缺页，就做新页。缺的型号出详情。搜得到的词，站里没有对应页，按这个词做详情。广告来意和现有页对不上，按这条来意做营销落地页。采购词没有承接，补厂家、OEM、起订量这类页。这些走内容运营。营销页接的是：这类人来了，站里要有一页对着他们。

原因指到站外或系统结构，把问题和页指清楚，交给人做。核投放和 SEO，调渠道预算，查流量质量，改导航、筛选、同义词、表单长度、客服话术。

演示站这一次：先改主力详情第一屏，把参数挪上来。广告来的人如果在营销页几秒就走，再按询价来意做一版落地页。看进去这一层掉了，动手和留下还稳，表单和客服维持现状。

---

入口放在门户导航，打开就是这份诊断。漏斗和路径放在同一个智能体里。一期把流失定位和出活做完，意图等词能对上人再接。窗口用近 28 天，每天可以重算。
