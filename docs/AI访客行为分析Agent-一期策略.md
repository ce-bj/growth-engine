# AI 访客行为分析 · 一期策略

范勇健 · 2026-09-16  
读者：老板、研发、内容运营  
状态：评审三次后重写。七步体检 / 假设库 / 实时意图识别，一期不做。  
约束：**搜索词、广告词一期都对不上到访的人。** 不能按「这个人带着什么词来」打意图、出任务。

文档必须能回答三件事：我们有哪些意图、每条怎么打标、每个场景看见什么数、得出什么结论、做什么。

---

## 0. 一句话

访问结束后，用站内路径给这次访问打**意图**；用页上有没有走下去打**流失 / 摩擦 / 缺口**。  
近 7 天按「意图 × 标记」汇总到具体 URL，对上场景表，直接出内容任务。

不分析「这个月全站为什么掉」，不给在线的人打分，不把搜索词 / 广告词安到某个人头上。

---

## 1. 这次换的是问题

原先七步在回答：询盘少了，先全站体检，再钉层、钉页、对假设。一期做不到，也讲不明白。

现在回答：这次访问像哪类意图、在哪一类流失上卡住，对应做什么内容。  
每一行都是：**打标规则 → 数据表现 → 结论 → 行动**。

| 仍要保住 | 一期拿掉 |
|----------|----------|
| 钉到具体 URL | 111 条指标、三态、三问、假设库 |
| 诊断出任务，内容运营 / 运营助手做页 | 实时意图、在线访客大屏、当场弹窗 |
| 意图用站内路径打标 | 用搜索词 / 广告词到人 |
| | 按站外关键词自动做落地页 |
| | 工单上写「+N 条线索 / 月」 |

## 2. 你说的结构是对的，策略按三类场景写

老板手册其实也是这三块，外加以后才做的聚合、按时段换页。

| 类型 | 标的是什么 | 一期要不要 |
|------|------------|------------|
| **A. 意图 × 流失** | 人来干什么，卡在漏斗哪一步 | 要。主场。 |
| **B. 摩擦 / 失效** | 按钮点了没反应，不是内容问题 | 要。一条就够。 |
| **C. 内容缺口** | 站内搜了没有 | 要。唯一带「词」的新建页。 |
| D. 站外词落地页 | 搜索词 / 广告词到人再做页 | 不做。词对不上人。 |
| E. 实时干预、热力、回放 | 人还在线上就弹窗 | 不做。 |

注意：**意图和流失不要用同一套数打两套标。**  
意图只看「去过哪些页、点过询价没有」。  
流失才看「停够没有、过没过首屏、表单交没交」。  
否则策略表会写成两遍。

## 3. 我们有哪些意图，怎么打标

打标对象：一次**已结束的访问**（同一 cookie，无操作 30 分钟或过 0 点算新访问）。  
不是在线实时分。不是搜索词、广告词。

一次访问只打一个主意图，**深的覆盖浅的**：

要询价 > 做比较 > 看产品 > 找资料 > 入口了解

| ID | 意图 | 打标规则（同时满足） | 不是什么 |
|----|------|----------------------|----------|
| I1 | 入口了解 | 没进过产品详情、没进过表单/联系页、没点过询价 CTA；进站第一页是首页 / 列表 / 关于我们 | 不是「搜索来的人」。渠道能拆就拆，词不能拆。 |
| I2 | 看产品 | 访问了 ≥1 个产品详情，且不够 I3 / I4 | 不是「搜了型号词进来」。只看他进了详情。 |
| I3 | 做比较 | 访问了 ≥2 个不同产品详情（或方案页），且不够 I4 | 不靠竞品搜索词。 |
| I4 | 要询价 | 点过询价 / 获取报价 CTA，或打开过联系页 / 表单页，或表单字段有过焦点 | 不靠广告「报价」词。 |
| I5 | 找资料 | 未到 I2–I4，但访问了文章 / FAQ / 下载，或发生过站内搜索 | 站内搜的词可以记下，供缺口场景用；主意图仍是找资料。 |

页面类型从站点信息取（首页、列表、详情、文章、联系、表单）。类型标错，意图就会标错。

近 7 天把打过标的访问汇总到页上：这页上 I2 多少人、其中浅看流失多少。出任务看的是这张汇总，不是某个人还在线。

建议：该页近 7 天 UV < 30，或某意图在该页 < 20 人，不出任务。

## 4. 流失、摩擦、缺口怎么打标

这些标记打在**同一次已结束的访问**上，和意图分开。

### 4.1 流失点（漏斗没过去）

| ID | 流失点 | 打标规则 | 对应漏斗 |
|----|--------|----------|----------|
| L1 | 浅看就走 | 当天只看 1 页，停留 < 15 秒（或未过首屏），且没有询价点击、没有表单开始 | 到达 → 看进去 |
| L2 | 看了没问 | 已经看进去（停留 ≥ 15 秒，或过了首屏，或看了 ≥2 页），但没有询价点击、没有表单开始 | 看进去 → 动手 |
| L3 | 动了没留 | 有询价点击或表单开始，没有提交成功、没有留资 | 动手 → 留下 |

「看进去」用停留或首屏二选一，站点能埋哪个用哪个；缺哪个就标数据缺口，不许拿 0 冒充没问题。

### 4.2 摩擦（技术，不是内容）

| ID | 标记 | 打标规则 |
|----|------|----------|
| F1 | 点击无后续 | 询价按钮或主导航点击后，没有跳转、没有表单出现、没有提交。一期用「点击次数高、后续事件接近 0」按页 / 按按钮汇总，不做 rage click 引擎。 |

### 4.3 内容缺口

| ID | 标记 | 打标规则 |
|----|------|----------|
| G1 | 站内搜了没有 | 站内搜索某词返回 0 结果，随后离开。词能挂在这次访问上。没有站内搜索的站点，整类停用。 |

## 5. 一期场景表

场景不是意图 × 流失的全表。只收**能出任务**的组合。  
每一行：谁（意图）× 卡在哪（标记）→ 看见什么数 → 结论 → 行动。

### A. 针对意图 + 流失点

#### A1 · 入口了解 × 浅看就走 → 改入口

| | |
|--|--|
| 意图 / 标记 | I1 × L1 |
| 数据表现 | 近 7 天进站第一页是首页或列表；只看这一页；停留短 / 不过首屏。有渠道时可看搜索、广告来的是不是更差。 |
| 结论 | 入口没把人带进产品。一期**不能**说成「某条搜索词没接住」。 |
| 行动 | 改首页 / 列表首屏：主力型号、询价入口上移。不按站外词生成新落地页。 |
| 谁做 | 内容运营改入口页 |
| 手册 | C-01 |

#### A2 · 看产品 × 浅看就走 → 改详情首屏

| | |
|--|--|
| 意图 / 标记 | I2 × L1（钉到该详情 URL） |
| 数据表现 | 该产品详情人够多；停留短或不过首屏；询价 CTA 几乎没点。 |
| 结论 | 这一页第一屏没接住。常见是公司介绍在上、型号参数在下。 |
| 行动 | 改这一页首屏：型号、关键参数、「获取报价」上移。不编造规格。 |
| 谁做 | 运营助手改产品详情；没有 Skill 则内容运营改页 |
| 手册 | C-01 / C-02；原贯穿案例 |

#### A3 · 看产品 × 看了没问 → 补询价和信任

| | |
|--|--|
| 意图 / 标记 | I2 × L2 |
| 数据表现 | 该详情停留不短或已过首屏，询价点击仍很低。 |
| 结论 | 人看进去了，页上不像能询价，或不敢点。 |
| 行动 | CTA 改成「获取报价 / 要样品」；旁边补认证、案例、交货。 |
| 谁做 | 内容运营或运营助手改现有页 |
| 手册 | C-02、A-02 |

#### A4 · 要询价 × 动了没留 → 降表单门槛

| | |
|--|--|
| 意图 / 标记 | I4 × L3 |
| 数据表现 | 表单有开始（焦点或填写），提交很少。 |
| 结论 | 字段多、一上来要敏感信息，或旁边没有「不会乱打」的说明。 |
| 行动 | 建议减到姓名 + 联系方式，其余选填；表单旁加信任说明。不自动改 CRM 必填。 |
| 谁做 | 内容运营出方案，运营 / 销售确认字段 |
| 手册 | B-04、B-05、C-04 |

#### A5 · 做比较 × 看了没问 → 一期后置

比较意图能打标，但一期先不出任务（选型表、对比页容易和详情改版抢同一批人）。二期再开。  
找资料 × 浅看，同样后置，避免文章页改不完。

### B. 针对摩擦

#### B1 · 点击无后续 → 技术工单

| | |
|--|--|
| 标记 | F1（可发生在任一意图上，优先于内容场景） |
| 数据表现 | 同一询价按钮或导航：点击高，后续跳转 / 表单 / 提交接近 0。 |
| 结论 | 不是文案问题，是点了没反应。 |
| 行动 | 工单给前端：URL、按钮文案、影响人次。诊断层不编内容。 |
| 谁做 | 技术 |
| 手册 | B-01、B-03 |

### C. 针对内容缺口

#### C1 · 站内搜了没有 → 补这一页

| | |
|--|--|
| 意图 / 标记 | I5 过程中记下的站内词 × G1 |
| 数据表现 | 某站内搜索词近 7 天多次 0 结果，搜完人走。 |
| 结论 | 进了站的人已经告诉我们缺什么。不是百度 / Google / 广告后台里的词。 |
| 行动 | 像型号 → 新建或补详情；像问题 → 补 FAQ / 指南。 |
| 谁做 | 内容运营，一期人审 |
| 手册 | E-01、E-02 |

---

同一页同时命中：B1 优先；其余按 C1 > A1 > A2 > A3 > A4。一期每页最多 2 条任务。

运营自己知道要做哪条站外词的落地页，只能在任务上**手填词**。系统不许写成识别出来的来路意图。

## 6. 输入

| 输入 | 粒度 | 用于 |
|------|------|------|
| 页面 URL、页面类型 | 页 | 意图打标、钉任务 |
| 一次访问里去过哪些页 | 访问 | I1–I5 |
| 询价 CTA 点击、表单焦点 / 提交 | 访问 / 页 | I4、L2、L3、F1 |
| 停留时长；过首屏（滚动或时长，能做哪个用哪个） | 访问 / 页 | L1、L2 |
| 是否进站第一页 | 访问 | A1 |
| 渠道（搜索 / 广告 / 直接 / 外链），有就用 | 访问 | A1 拆分，可选 |
| 站内搜索词、是否 0 结果、搜后是否离开 | 访问 | I5、C1 |

不要接进打标：**自然搜索词、广告关键词、词到人的拼接。**  
搜索控制台、广告后台的词表可以给人看，不能当成「这些人就是搜这个进来的」。

窗口：近 7 天，每天可重算。不做对比过去 4 周。

## 7. 输出

给人看：钉哪一页、主意图是什么、卡在哪个标记、依据数字、做什么。  
给下游：任务。任务上不写搜索词 / 广告词，除非 C1 的站内搜索词，或运营手填。

改现有页示例：

> 修改产品：https://…/ss-ball-valve  
> 场景 A2（看产品 × 浅看就走）  
> 首屏改成型号 + 关键参数 +「获取报价」。不要编规格。

新建页主要来自 C1。意图任务 ID 用场景 + 页或站内词，例如 `vb-a2-ss-ball-valve`、`vb-c1-DN100`。这是任务标识，不是某个访客的搜索意图。

一期人确认后才派发。不写预期多留几条。复盘看这一页停留、CTA、提交有没有动。

## 8. 产品上打开是什么样

1. 页头：近 7 天最重的一条场景，人话结论。  
2. 表：场景、意图、流失/缺口、页面、人数、任务按钮。没有「来路词」列；C1 才出现站内搜索词。  
3. 可展开该页：来了、看进去、动手、留下。用来核对，不是另一套引擎。  
4. 抽样已结束路径：从哪进、停多久、走到哪、系统打的意图。路径上没有搜索词 / 广告词。

不要做：在线 200 人、高中低意向饼图、按搜索词拆人、热力图、回放、对着当前访客弹窗。

---

## 9. 贯穿案例

主力球阀详情近 7 天人够多。

- 访问被打成「看产品」，在该页浅看就走 → **A2** → 改这一页首屏。  
- 看产品且已看进去，仍不点报价 → **A3**。  
- 要询价，表单没交完 → **A4**。  
- 访问停在入口了解，首页浅看就走 → **A1** → 改首页。  
- 站内搜「DN100」0 结果后离开 → **C1** → 补页。

对外说：「询盘少，是球阀详情第一屏没接住。」  
不要说：「搜不锈钢球阀 DN100 进来的人落到首页秒退。」

## 10. 和手册怎么交代

| 手册 | 一期 |
|------|------|
| A 意图驱动 | 第 3 节五条意图 + A1–A4；不实时、不到人 |
| B 流失信号 | L3 表单、B1 点击无后续；rage click / 热力不做 |
| C 漏斗断点 | L1–L3 就是三个流失点，落到 A1–A4 |
| D 聚合 | 不单列，已含在「这页这意图人多、流失高」 |
| E 内容缺口 | 只做 C1 站内搜索 |

二期：搜索词 / 广告词到人、按词做落地页、A5 做比较、实时干预。

## 11. 研发验收

1. 访问结束后能打出 I1–I5 之一，规则里没有搜索词 / 广告词。  
2. 同一次访问能打 L1 / L2 / L3 / F1 / G1（可空）。  
3. 近 7 天按页汇总后，能命中 A1–A4、B1、C1，阈值可配。  
4. 任务带：场景 ID、意图、标记、URL、一句话结论、行动类型。  
5. 缺数标数据缺口。无站内搜索则停用 C1。  
6. 界面不展示在线意图，不按站外词拆人。

讲评审：第 2、3、5 节。其余当附录。
