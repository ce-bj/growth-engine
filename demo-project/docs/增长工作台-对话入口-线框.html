0 · 一个助手，两种打开方式

壳相同，冷启动不同
门户情境按钮人在产品、内容、询盘。点「用助手改这一页」→ 侧栏打开，对象已经带上。高频，少说话。
工作台顶栏总入口人主动要聊。打开同一侧栏，能力全开：改产品、发内容、挖客户、解读本月体检。解读不高频，但对话框必须能接。
定时体检仍后台跑两种入口都不触发重算。问询盘、点确认执行，都读已落库的快照和工单。
产品/内容页按钮→侧栏 · 带着这一页开工 工作台 · 运营助手→侧栏 · 全量对话
