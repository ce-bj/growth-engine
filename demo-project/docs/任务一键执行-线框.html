诊断出任务之后，一键执行接在哪

一键跳过的是「再把这件事从零说一遍」。一键停住的是「对外发出去」。任务必须是填好参数的工单，不能是一段建议。

0 · 三种任务，三种「一键」

不是所有任务都点一下就对外生效
确认后执行 · 内容/获客一键 = 带着 URL 和改法开工，出草稿或名单。人再点「发布 / 发信」。这是原型主路径。
自动执行 · 技术止血没有一键。sitemap、404、询盘链路，系统自己做完，手机只收结果。人不进后台。
只出方案 · 站外/花钱没有执行键。投放、外链、改预算只给建议，避免假装能改。

1 · 诊断结束：出工单，不出作文

每张卡已经绑好站点、页面、Skill、改法

现在增长诊断给的是「帮我修改产品 + 提示词」，人还要复制去聊天。一键要成立，卡上必须已经是可跑参数：对象 URL、改哪、用哪条 Skill、停在哪一档。

4 · 不要把「一键」做成这两种

一键直接群发 / 直接上线：对外不可逆，默认不能。获客计划里「自动发送」只发已经确认过的那封信。
